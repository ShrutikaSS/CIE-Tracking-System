Introduction
The ATM Simulation System is a software application that simulates basic ATM operations such as user authentication, balance inquiry, deposit, withdrawal, and mini-statement generation. The system uses structures to organize account data and file handling to store account and transaction details permanently.
Objectives
To simulate ATM operations
To use structures for data organization
To apply file handling for permanent storage
To maintain transaction records
